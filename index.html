# 金字塔隐私权说明

# 背景

金字塔插件是一款公司内网使用的辅助插件，提供快速切换账号、mock 数据等能力。插件需要请求以下一些权限

# 一、请求浏览器 tabs、webRequest、webNavigation 权限

  • 获取当前测试的 URL 信息和一些公司内网的请求信息
  • 帮助 mock、代理公司内网请求

# 二、请求 storage 本地存储权限

  • 存储用户的配置文件使用

# 三、请求 scripting 权限

  • 会在 debug 页面插入排查使用的脚本，以协助完成 debug 能力

# 四、用户活动记录

我们会收集一些关于您使用我们插件的活动记录，例如：

• 打开插件 • 点击登录 • 打开登录二维码 • 收藏账号等

这些信息旨在帮助我们改进并提高我们的插件服务能力，以便更好地服务于您。我们不会将这些信息共享给第三方机构或个人，除非我们基于法律或政府规定需要如此，或者您同意共享。

# 五、存储与保护

我们将尽最大努力保护您的个人信息的安全。我们会采用合理且必要的措施来保护您的个人信息，避免被未经授权的访问、使用或泄漏。我们在处理您的个人信息时，也会遵守相关法律法规。

# 六、隐私权政策修改

我们可能会不时修改本隐私政策，以反映变化的业务需求、法律法规的调整，或其他原因。如果我们进行任何重大修改，我们会在插件首页发布更新版本的提示。我们建议您定期查看本隐私政策以了解最新信息。

# 七、联系我们

如果您对我们的隐私政策或我们对您个人信息的处理有任何问题或疑虑，请联系我们的客户服务。我们将竭诚为您解答疑问，解决相关问题。
